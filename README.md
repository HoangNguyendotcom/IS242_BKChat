## Getting Started

Follow these instructions to get a copy of the project running on your local machine.

### Prerequisites

- Python 3.x
- Node.js and npm
- Docker and Docker Compose

### Installation and Setup

1. Clone the repository
   ```
   git clone https://github.com/username/repository.git
   cd repository
   ```

2. Activate the virtual environment
   ```
   source venv/bin/activate
   ```

3. Install backend dependencies
   ```
   pip install -r requirements.txt
   ```

4. Install frontend dependencies
   ```
   npm install
   ```

5. Start the Docker container
   ```
   docker compose up -d
   ```
   Note: The `-d` flag runs containers in the background (detached mode)

6. Start the backend server
   ```
   cd backend
   python run.py
   ```

7. In a new terminal, start the frontend development server
   ```
   cd frontend
   npm run dev
   ```

## Usage

Access the application by navigating to `http://localhost:3000` in your web browser (or whichever port your frontend is configured to use).
